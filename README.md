# Bunts App

A personal mobile app (iOS/Android, React Native/Expo) for managing my own Yahoo Fantasy Baseball team.

## What it does
- Views my roster and suggests optimal lineups / start-sit calls (read-only — I apply changes myself in the Yahoo app)
- Tracks ongoing performance of players on my team
- Keeps a running season tally of keeper candidates for next season
- Sends push notifications when a rostered player is announced not starting

## Scope
Personal, single-league, single-user project. Not distributed publicly. Uses read-only access to the Yahoo Fantasy Sports API.
